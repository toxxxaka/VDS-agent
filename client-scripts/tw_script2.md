# Параметры tw_script2.py

Скрипт собирает диагностическую информацию о сервере и выводит её в терминал. Запуск без параметров выполняет все доступные секции, а в конце предлагает ввести домен для поиска конфигурации виртуального хоста и путей логов. Для наиболее полного вывода используйте `sudo`.

## Параметры

| Параметр | Краткое описание |
| --- | --- |
| `--only СЕКЦИИ` | Выполнить только перечисленные через запятую секции, например `--only network,vpn,fw`. Пробелы вокруг названий допустимы. |
| `--timeout СЕКУНДЫ` | Максимальное время выполнения каждой диагностической команды. По умолчанию 10 секунд; значение должно быть больше нуля. |
| `--slow СЕКУНДЫ` | Пометить команды, которые выполнялись дольше указанного времени. По умолчанию 2 секунды; значение не может быть отрицательным. |
| `--list` | Показать доступные секции и завершить работу. |
| `--no-vhost` | Не спрашивать домен и не выполнять интерактивный поиск vhost в конце. |
| `-h`, `--help` | Показать встроенную справку. |

## Секции для `--only`

| Секция | Что проверяет |
| --- | --- |
| `general` | Время работы, нагрузку, память и ресурсы системы. |
| `disk` | Свободное место, inode и крупнейшие каталоги. |
| `proc` | Процессы с высокой нагрузкой и процессы-зомби. |
| `systemd` | Сбойные службы, ошибки журнала и события OOM. |
| `network` | Слушающие порты, соединения и сетевые интерфейсы. |
| `ssh` | Настройки SSH и недавние события авторизации. |
| `fw` | Состояние UFW, iptables и Fail2ban. |
| `vpn` | Службы VPN и прокси, WireGuard, x-ui/3x-ui. |
| `web` | Последние строки журналов ошибок веб-серверов и PHP-FPM. |
| `db` | Состояние MySQL и список запросов. |
| `docker` | Контейнеры и использование места Docker. |
| `mail` | Размер почтовых очередей Exim и Postfix. |
| `vhost` | Интерактивный поиск конфигурации по домену и путей её логов. |

При `--only vhost` выполняется только запрос домена. Если указана `--no-vhost`, запрос домена пропускается даже при выборе секции `vhost`. Недоступные в системе команды пропускаются; без прав root часть результатов может быть неполной.

## Примеры

```bash
sudo python3 /home/ai/tw_script2.py --no-vhost
sudo python3 /home/ai/tw_script2.py --only network,vpn,fw --timeout 5
sudo python3 /home/ai/tw_script2.py --only vhost
python3 /home/ai/tw_script2.py --list
```
